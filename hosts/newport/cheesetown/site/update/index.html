Update to Cheesepack v2

Cheesetown now runs Minecraft 26.3. If you're using Cheesepack v1, you'll need to update before joining.

Download a fresh copy

Download Cheesepack v2, then choose Add Instance → Import in Prism Launcher and select the ZIP. Pick Java 25 and launch.

Keep your old instance until you've copied any screenshots or single-player worlds you want.

Update your existing Prism instance

If you installed v1 from our auto-updating ZIP, you can keep that instance:

  1. Close Minecraft. Right-click your Cheesepack instance in Prism and choose Edit.
  2. Open the Version tab. Select Minecraft, click Change version, and choose 26.3.
  3. Select Fabric Loader, click Change version, and choose 0.20.1.
  4. Launch the instance. Packwiz will download the v2 mods before Minecraft opens. You can rename the instance to Cheesepack v2 too.

Leave the pre-launch command as it is. If you installed the .mrpack instead, use the fresh ZIP above.

Your builds and inventory are still on the server. Join cheesetown.rocks as usual.
